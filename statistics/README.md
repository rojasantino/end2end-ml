# Statistics Mastery Roadmap

A practical Statistics learning roadmap covering **8 stages**, **40+ concepts**, and **20+ practical exercises/projects**, progressing from fundamental descriptive statistics to multivariate analysis, Bayesian methods, time series, and experimental design.

## 📊 Roadmap Overview

| Stage | Topic                                            |
| ----- | ------------------------------------------------ |
| 1     | Descriptive Statistics                           |
| 2     | Probability & Distributions                      |
| 3     | Hypothesis Testing                               |
| 4     | A/B Testing                                      |
| 5     | ANOVA, Chi-Square & Non-Parametric Tests         |
| 6     | Correlation & Regression                         |
| 7     | Bayesian Statistics & Time Series                |
| 8     | PCA, Multivariate Analysis & Experimental Design |

The concepts are supported with practical Python-based exercises and real-world datasets.
